How it works

Eosnox Labs is the laboratory's desktop software: registration, test entry, billing, quality control and printed reports. It also receives results directly from two analyzers over network cables, so nobody re-types machine values.

RegisterThe animal gets an HR number, e.g. HR-20261010-0001.
Run on analyzerStaff type that HR number on the analyzer as the patient.
Result arrivesStored exactly as the analyzer sent it, and linked to the HR number.
PrintOne report with the lab's own header, footer and signatures.
  • Unics H33 (hematology / CBC) sends each result to the PC by itself, a few seconds after the run, with WBC, RBC and PLT histograms.
  • Unics 100plusV (chemistry) keeps its results in its own file. The PC reads that file every 30 seconds. It only reads; nothing on the analyzer is changed.
  • Reference ranges and high/low flags come from each analyzer's own setup, not from the software.

Install

  1. Unzip the folder. Right-click Eosnox Labs - Windows Setup.zip → Extract All… → Extract. Do not run the installer from inside the zip.
  2. Start the installer. In the extracted folder, double-click Install Eosnox Labs.bat.
    If Windows shows "Windows protected your PC"Click More info, then Run anyway. This appears for any file copied from another computer.
  3. Let it run. A black window shows each step. If Python 3.12 is not on the PC, it is installed for you (about 1 minute). Then the program and its libraries are installed.
  4. Allow the firewall rule. Windows asks "Do you want to allow this app to make changes to your device?" Click Yes. This lets the H33 deliver results to this PC.
  5. Finish. The window ends with "Eosnox Labs is installed." Type Y and press Enter to open it now.

The installer creates an Eosnox Labs icon on the Desktop and in the Start menu, plus Eosnox Labs Guide (this page) and Uninstall Eosnox Labs in the Start menu.

First start

  1. Sign in with user admin and password admin.
  2. Change the password. Open Master → Lab details & password, scroll to Change password, enter the current password admin and a new one, and save.
  3. Enter your laboratory details on the same page: name, tagline, address, phone, email. Click Save details. These print at the top of every report.
  4. Set the report layout (header note, footer, signature labels). See Report layout.
  5. Add your tests, profiles, referring doctors and hospitals under Master, as you need them.

Connect the H33

The H33 sends its results to a fixed address, 192.168.19.104, on port 8001. The PC port it is cabled to must take that address. Eosnox Labs does this for you.

On the H33

  1. Open Setup → Ethernet Port Setup.
  2. Set Server IP to 192.168.19.104 and Port Number to 8001. Leave the H33's own IP as it is (for example 192.168.19.109).
  3. Turn Auto Transmission on, and save.

On the PC

  1. Plug the Ethernet cable from the H33 into the PC port you have set aside for it. Turn the H33 on.
  2. In Eosnox Labs open Instruments → Analyzers & network.
  3. On the Unics H33 card you will see "192.168.19.104 is not on any adapter". Under Adapter cabled to the H33 choose the port the cable is in (for example Ethernet 2), then click Add 192.168.19.104.
  4. Windows asks for permission. Click Yes. The card now shows "✓ 192.168.19.104 is on Ethernet 2" and the state changes to Waiting.
  5. When the H33 connects, the state becomes Connected. It stays this way after restarts.
That port now belongs to the analyzersThe chosen port is given a fixed address, so it no longer works for the office network or internet. To give it back, click remove next to the H33 server address in the adapter table at the bottom of the page.
If a Windows Firewall box appears("Windows Defender Firewall has blocked some features of this app") tick both Private and Public networks and click Allow access.

Connect the 100plusV

The 100plusV keeps results in its own file. Eosnox Labs signs in to the analyzer and reads that file every 30 seconds. The analyzer's remote sign-in ("SSH") must be switched on once.

One-time: switch on SSH at the analyzer

Do this once, preferably with your Unics service engineer. You need a USB keyboard plugged into the analyzer. The screen will not show what you type in step 2; type carefully.

  1. With the analyzer program running, press Ctrl+Alt+F2 and wait 2 seconds.
  2. Type the analyzer's user name (pi) and press Enter, then its password and press Enter.
  3. Type sudo systemctl enable --now ssh and press Enter (type the password again if asked).
  4. Press Ctrl+Alt+F7 to go back to the analyzer program.
Never change anything else on the analyzerDo not change its user name or password, and do not edit or delete its program files. Eosnox Labs only needs to read them.

On the PC

  1. Plug the Ethernet cable from the 100plusV into the second PC port. Leave that port on its normal (automatic) setting.
  2. Open Instruments → Analyzers & network. On the Unics 100plusV card:
    • Analyzer address: raspberrypi.local (already filled in)
    • User: pi
    • Password: the analyzer's password. It is saved in Windows Credential Manager, not in a file.
  3. Click Save, then Read now.
  4. Within a few seconds the state becomes Connected, "Results stored" shows how many results the analyzer holds, and "Next patient ID on the analyzer" is filled in.
One port for both analyzers?It works through a small network switch, but one port per analyzer is more reliable. If you share a port, connect the H33 first (above). Windows then also keeps a self-assigned address on that port so the 100plusV stays reachable.

First test run: a worked example

Do this once after setup to prove both analyzers deliver to the right animal.

1. Register the animal

Example
Registration → New patient registration: Patient name Bruno, Species Dog, Age 4 years, Sex Male, Owner name R. Mehta. Select the tests (for example CBC and SGPT) and save.
The registration gets the HR number HR-20261010-0001. Write it on the sample tube.

2. Run the CBC on the H33

  1. On the H33 start a new sample. In Patient No. type the HR number without dashes: HR202610100001. The field holds only 15 characters, so the version with dashes gets cut off (that still matches, but it's better to type it without dashes).
  2. Fill in name, species and so on if you like, and run the sample.
  3. A few seconds after the H33 shows the result, open the registration (Registration → Registrations → HR-20261010-0001). Under Analyzer results you see the full CBC with the H33's own ranges, H/L flags and histograms.

3. Run SGPT on the 100plusV

  1. On the 100plusV, enter the HR number in Patient Name: HR-20261010-0001 (or HR202610100001).
  2. Run SGPT.
  3. Within 30 seconds SGPT appears in the same Analyzer results section, with the range from the 100plusV's test setup.

4. Print

On the registration page click Open report and print it. The analyzer results print with your laboratory header, footer and signature labels, and the H33 histograms if that option is on.

What counts as a matchDashes, spaces, upper/lower case, the "HR" letters and leading zeros in the last part are ignored. All of these link to HR-20261010-0001: HR-20261010-0001, HR202610100001, hr 20261010 1, 20261010-1.

Daily routine

  1. Start of day: turn on the analyzers, then open Eosnox Labs. Check Instruments → Analyzers & network: the 100plusV shows Connected, the H33 shows Waiting or Connected.
  2. For each sample: register first, then type the HR number on the analyzer, then run.
  3. Check the inbox: the number next to Instruments in the menu is how many results are waiting to be linked. Clear them before reports go out (see Results inbox).
  4. Run QC as your lab requires and record the values (see Quality control).
  5. End of day: close Eosnox Labs before switching off the PC. Back up the data folder regularly (see Backup).

Keep Eosnox Labs open while analyzers are running. H33 results sent while it is closed are not received. The 100plusV is not affected: its results are read when Eosnox Labs opens again.

Results inbox

Instruments → Results inbox lists analyzer results that are not linked to a registration yet. A result lands here when:

  • nothing was typed on the analyzer, or the HR number was mistyped;
  • the result arrived before the registration was created. Click Match again by HR no. once it exists;
  • it is a repeat: the registration already has this test from this analyzer.

Link a result by hand

Type or pick the HR number in the box on that row and click Link. To undo, use unlink. The result goes back to the inbox unchanged.

Repeat runs

A registration holds one result per test from each analyzer: one CBC from the H33, and one of each chemistry test from the 100plusV. When a test is run again, the new run waits in the inbox marked "Repeat" with a link to the earlier run.

  • Replace with this run uses the new run and sends the earlier one back to the inbox. Both keep their values exactly as received.
  • If the earlier run is the right one, leave the repeat in the inbox.

Quality control

When you run QC on the H33, it sends the control's file number, lot, level, expiry and each parameter's target and limit. It does not send the measured QC values (they arrive as ***). Record them from the H33 screen:

  1. Open Instruments → QC from analyzers. Each H33 QC run is listed with its lot, level and expiry.
  2. Click Record value next to a parameter. The QC form opens with test, level, lot, analyzer and target already filled in.
  3. Type the value shown on the H33 and save.
  4. Master → Quality control lists every QC run with its status against the lot's mean and SD: Accept within 2 SD, Warning between 2 and 3 SD, Reject beyond 3 SD. Investigate a rejected run before releasing patient results for that test.

For the 100plusV and manual tests, record QC directly under Master → Quality control.

Rules that keep results safe

  • Analyzer results cannot be edited or deleted, by anyone, in any screen. The database itself refuses it. Only the link to a registration can change.
  • Ranges come from the analyzer that produced the result, because the right range depends on that machine's setup.
  • One result per test per analyzer on each registration. Repeats wait in the inbox until a person decides.
  • The 100plusV is only read, never written to. Do not change its user name, password or program files.
  • Every raw message from the analyzers is also kept as a file in the data folder (instrument_data\raw).

Backup, update, uninstall

Backup

  1. Close Eosnox Labs.
  2. Copy the folder %LOCALAPPDATA%\Programs\Eosnox Labs\data to a USB drive or network share. Name the copy with the date.

To restore, close Eosnox Labs and copy the saved data folder back to the same place.

Update to a newer version

Close Eosnox Labs, unzip the new setup folder and run Install Eosnox Labs.bat again. Your data, settings and analyzer setup are kept.

Uninstall

Start menu → Eosnox Labs → Uninstall Eosnox Labs (or Uninstall Eosnox Labs.bat in the setup folder). The laboratory data is kept unless you type DELETE when asked. Python 3.12 stays installed. Remove it under Windows Settings → Apps if nothing else uses it.

Troubleshooting

What you seeLikely causeWhat to do
H33 card: "192.168.19.104 is not on any adapter"The H33's address was never added, or was removed.Add it again: Connect the H33, PC steps 2–4.
H33 card: "Cannot listen on 192.168.19.104:8001 … in use"Another program is using port 8001, or Eosnox Labs is open twice.Close other copies and test programs, then reopen Eosnox Labs.
H33 stays Waiting after a runCable, H33 settings, or the firewall.Check the cable and the H33's Server IP / Port / Auto Transmission. Run the installer again to re-add the firewall rule.
100plusV: "wrong password"Password not saved or mistyped.Enter it in the 100plusV card and click Save.
100plusV: "SSH is off on the analyzer"SSH was switched off.Repeat the one-time SSH step.
100plusV: "analyzer not on the network" / "Cannot find raspberrypi.local"Analyzer off, cable out, or Windows cannot look up the name.Check power and cable, then Read now. If it still fails, open Command Prompt, run arp -a, find the line whose physical address starts with 2c-cf-67, b8-27-eb, dc-a6-32, d8-3a-dd or e4-5f-01, and enter that IP address as the Analyzer address.
100plusV: "SSH key changed"A different 100plusV unit (or a reinstalled one) is now connected.If that is expected, delete the file data\instrument_data\known_hosts and click Read now.
100plusV: "Connection to the analyzer dropped twice in a row"Loose cable or the analyzer restarted.Check the cable. It retries every 30 seconds.
Result not on the registrationHR number not typed, mistyped, or the test is a repeat.Open the Results inbox and link it.
Dates on 100plusV results are wrongThe 100plusV's clock is wrong. It has no clock battery and resets when powered off.Set the date in the analyzer's own settings each time it is switched on.
Eosnox Labs window is blank or does not openMicrosoft Edge WebView2 is missing.Install it from https://go.microsoft.com/fwlink/p/?LinkId=2124703, then open Eosnox Labs.
"Eosnox Labs could not start"See the message.Send the file data\logs\eosnox.log to your support contact.
"Eosnox Labs is already open"It is running in another window.Use the open window (check the taskbar).
